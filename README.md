# node sunshine

### overview
project is intended to show an interactive, node-based UI for checking the weather at your layovers

### roadmap
project is a light demo of reactflow intended for experimentation & fun
- [ ] Scaffold: react project running locally

    - [ ] function: start with one mode, option to add more
- [ ] Docker: image for containerization
    - [ ] function: nodes should query actual cities, dates, weather
- [ ] Deployment: TBD by budget
